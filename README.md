# Personal Portfolio 🚀

A modern, high-performance developer portfolio built with React, Vite, Tailwind CSS, and GSAP. Designed to showcase my projects, skills, and academic background with responsive design and smooth animations.

## ✨ Key Features
- **Bilingual Support:** Full localization support (Arabic & English).
- **Theme Modes:** Light and Dark themes optimized with custom Glow/Vibrant colors.
- **Smooth Animations:** GSAP integration for modal transitions and lifecycle animations.
- **Optimized Assets:** High-performance preview media replacing heavy embedded components for optimal scrolling.
- **Fully Responsive:** Custom SVG wave dividers and responsive layout across all screen sizes.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js + Vite
- **Styling:** Tailwind CSS
- **Animations:** GSAP
- **State Management:** Redux Toolkit
- **Icons:** Lucide React
- **Deployment:** Vercel
